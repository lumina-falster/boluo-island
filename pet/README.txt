🍍 菠萝岛桌宠 · 使用说明
========================

【启动】
双击 START_PET.bat，小菠萝会出现在屏幕右下角。
首次启动会自动在桌面创建「菠萝岛桌宠」快捷方式，以后点它即可。

【操作】
拖动  ：移动位置（关掉后自动记忆）
单击  ：展开 / 收起详情面板（全部地块统计 + 最近 8 块倒计时）
右键  ：立即刷新 / 打开管理网页 / 设置仓库 / 退出

【功能】
- 气泡实时显示最近一块果实的成熟倒计时
- 快熟 / 成熟时弹 Windows 桌面通知
- 每 3 分钟自动从 GitHub 同步数据，断网时用上次数据继续倒计时
- 表情随状态变化：睡觉 → 微笑 → 兴奋 → 蹦跳催收

【数据从哪来】
只读 GitHub 公开仓库（默认 lumina-falster/boluo-island），无需任何账号令牌。
种果实 / 收获 / 修改数据请在手机网页上操作：
https://lumina-falster.github.io/boluo-island/

【分享给有自己岛屿的朋友】
让对方先按项目 README 部署他自己的仓库，
然后在这台电脑上：右键桌宠 → 设置仓库，填他的用户名和仓库名。

【开机自启（可选）】
Win + R 输入 shell:startup 回车，
把桌面的「菠萝岛桌宠」快捷方式复制一份进去。

【被 Windows 拦截了？】
提示"已保护你的电脑"时：点「更多信息」→「仍要运行」。
或右键 START_PET.bat → 属性 → 勾选「解除锁定」→ 确定。

【环境要求】
Windows 10 / 11，无需安装任何软件。
